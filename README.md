# The Midnight Library 📚

A magical, dark-academia personal library built with GitHub Pages.

## Structure
- `index.html` — the library interface and reader
- `catalog.js` — book metadata
- `books/` — add personal/public-domain PDFs here only when appropriate

## Adding a book
1. Put the PDF in `books/`.
2. Add an entry to `catalog.js` with a relative path such as `books/dorian-gray.pdf`.
3. Commit. The shelf updates automatically.

Reading status, favourites, ratings and progress are stored locally in the browser.

> Keep copyrighted personal PDFs out of a public repository unless you have permission to redistribute them.
